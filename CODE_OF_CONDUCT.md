# Code of Conduct

## Our standard

Contributors and maintainers are expected to make participation welcoming and safe. Be respectful, assume good intent, write clearly, and focus criticism on the idea or code rather than the person.

Unacceptable behavior includes harassment, discrimination, threats, deliberate disruption, publishing private information, impersonation, and sharing credentials or private user material.

## Enforcement

Please report conduct concerns privately through the security contact path in [SECURITY.md](SECURITY.md), or contact a repository maintainer through GitHub. Maintainers may edit, hide, or remove comments, issues, and pull requests that violate this code, and may restrict participation when necessary to keep the project safe.

This code applies to the repository, issue tracker, pull requests, release discussions, and project-related community spaces.
